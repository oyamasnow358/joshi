# じょしの れんしゅう（MieeL）

助詞（は・が・を・に・へ・で・と・の・も・や・から・まで・より）を、カードを指で動かして学ぶ iPad 向けアプリです（特別支援教育向け）。

## 5つの モード × 5段階の レベル
- 🧩 **あなうめ**：絵と文を見て、（　）に助詞カードをスライドして入れる（★ を・が → ★★★★★ から・まで・より・や／（　）が2つ以上の文）
- ✅ **ただしい ぶん**：2〜4つの文から正しい文を選ぶ
- 🔤 **ならべかえ**：ことばカードと助詞カードを並べて文を作る（使わない助詞カードが混ざるレベルも。「ことば＋助詞」のまとまりの順番を入れかえても正解）
- 👂 **よみかた**：助詞の「は」は「わ」、ことばの「は（はな）」は「は」…（「はなは きれい」のような ひっかけも）
- ✏️ **かきかた**：聞いた文を正しく書いているのはどれ？（を／お、は／わ、へ／え）

文は約270（空欄 約300か所）。「こうえんで あそぶ」「いすに すわる」など、いれても文として成り立ってしまう助詞は選択肢に出ないように1文ずつ調整しています。

## 先生用せってい（⚙️ を 1.5秒 ながおし）
- 問題数、選ぶカードの数、**先生が選ぶ助詞**（例：「で」と「に」だけ）
- ヒント（間違えたら正しいカードが光る）、タップ操作、文字の大きさ、読み上げ、効果音、記録（CSV）

## A4 プリント（🖨️）
あなうめ（○をつける／書きこむ）・正しい文・ならべかえ・よみかた・かきかた。レベル・問題数・文字の大きさ・答えのページ・枚数を選べます。

ほかのアプリ（やすみの しゅくだい メーカー）からプリントを作れるよう `window.MieelPrintAPI` を持っています。
